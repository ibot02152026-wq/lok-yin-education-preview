3–6 歲 幼兒興趣班

38 個課程

創意藝術

4 個課程小手畫世界、色彩魔法師、故事繪本創作、紙藝小達人
小手畫世界 →

嘗試水彩潑灑、手指畫、拼貼、吹畫和彩砂畫，接觸不同繪畫材料，自由創作。

色彩魔法師 →

從紅、黃、藍三原色開始，透過混色實驗、彩虹製作、色彩拼圖及主題創作，觀察顏色變化。

故事繪本創作 →

聆聽故事、設計角色和繪畫場景，再學習簡單裝訂，製作並分享自己的繪本。

紙藝小達人 →

練習摺、剪、貼及捲紙，製作動物摺紙、立體卡片、剪紙窗花、紙盤面具及紙條拼貼。

領袖訓練

5 個課程小小領袖成長班、禮儀小天使、表達力訓練班、合作小勇士、小小解難王
小小領袖成長班 →

透過自我介紹、團隊遊戲、簡單分工、情緒表達及分享，輪流擔任組長和組員，練習聆聽與配合。

禮儀小天使 →

以日常情境和角色扮演，練習問好、分享物品、輪候及道歉，認識基本社交禮儀。

表達力訓練班 →

透過故事演說、簡單朗誦、情感表達遊戲及角色扮演，練習用聲音、動作和表情表達意思。

合作小勇士 →

參與協力運球、團隊拼圖、合作繪畫、集體故事創作及小組比賽，練習商議和互相配合。

小小解難王 →

透過邏輯遊戲、情境小劇場、選擇判斷、分享討論及反思，嘗試分析問題和調整方法。

遊戲才藝

5 個課程桌上遊戲樂園、小小魔術師、音樂律動班、趣味體能遊戲、故事劇場遊戲
桌上遊戲樂園 →

參與記憶、配對、簡單策略及合作遊戲，認識規則，練習輪候和面對勝負。

小小魔術師 →

學習紙牌、消失物品及繩結等簡單魔術，練習手眼協調和表演，可商議期末小型演出。

音樂律動班 →

透過拍手遊戲、節奏樂器、音樂律動及舞蹈遊戲，嘗試歌唱和節奏活動，毋須音樂基礎。

趣味體能遊戲 →

參與障礙賽、球類遊戲、平衡挑戰、跳圈圈及體能冒險，練習大肌肉動作和身體協調。

故事劇場遊戲 →

以角色扮演、故事接龍、即興表演、情境遊戲及故事分享，嘗試用聲音、動作和表情演繹角色。

黏土美術

黏土小天地 →

從搓、揉、捏、壓等基本操作開始，製作動物、食物、花卉及交通工具，也可自由創作。

黏土故事屋 →

製作故事角色和場景，配合創意拼貼、故事講述及作品分享，練習構思立體故事。

色彩黏土樂園 →

學習混色和漸變效果，製作立體動物、植物造型及主題作品。

黏土小飾品 →

製作戒指、手鏈、吊飾和胸針，並嘗試禮物包裝，練習細緻的手部操作。

卡通黏土工房 →

觀察熟悉的卡通角色，將人物特徵簡化成黏土造型，完成自己的角色作品。

畫室美術

水彩小畫家 →

學習濕畫法、乾畫法、漸變色和水分控制，進行主題創作，並分享及欣賞作品。

創意拼貼畫 →

運用紙張、布料及自然物製作平面和立體拼貼，嘗試主題創作及材料再利用。

創意油粉彩 →

體驗油粉彩的疊色、混色和刮畫效果，並以卡通人物為主題創作。

音樂小精靈舞動班 →

透過基本律動、簡單舞步、遊戲舞蹈及創意舞動，練習節奏感、身體協調和空間感，毋須舞蹈基礎。

小天鵝芭蕾夢 →

從基本站姿和手位開始，學習足尖舞步、簡單旋轉，並透過芭蕾故事和表演認識舞蹈。

小小韓流偶像班 →

學習適合幼兒的 K-POP 舞步，練習隊形變換，並參與舞蹈表演。

中文

故事小天地 →

透過故事聆聽、角色扮演、故事續寫及簡單朗讀，練習理解和表達。

詩詞童謠班 →

以朗誦、韻律遊戲、詩詞配畫、情境演繹及創意改編，接觸兒童詩詞和童謠。

拼音啟蒙 →

以拼音遊戲、字母拼讀及聲母韻母練習，接觸識字的基本工具；拼音系統及教學安排可先查詢。

英語

English Fun Time →

Phonics Playgroup →

從字母音開始，透過字母歌、發音遊戲、拼讀、配對及朗讀活動，建立拼音基礎。

Storytelling English →

以故事閱讀和角色表演為主，配合詞語配對、故事續寫及創意畫畫，練習聽、說、讀。

English Craft & Play →

在主題手工、作品分享和遊戲中學習英語詞語及簡單句子，練習理解課堂指令。

數學

2 個課程數學遊戲班、數感啟蒙
數學遊戲班 →

透過數字配對、圖形遊戲、排序、計數及邏輯拼圖，以具體操作接觸數學概念。

數感啟蒙 →

以點數遊戲、簡單加減、分組、圖形認識及生活情境，練習數量對應、數序和簡單運算。

運動

幼兒體適能 →

幼兒足球 →

以腳部控球、帶球繞障礙、簡單傳接、小場比賽及足球律動，接觸足球和團隊活動。

幼兒籃球 →

學習原地及行進拍球、雙手傳球和投籃，透過球類遊戲練習手眼協調。

感覺統合運動 →

透過平衡木、彈跳床、觸覺箱探索、重力遊戲及舒緩活動，接觸平衡和不同感官經驗。

辯論小高手學院 →

沙畫 →

禪繞畫 →

音樂活動 →

園藝活動 →
